# 星轨视界

中文 | [English](README.md)

一个基于 Web 的交互式 3D 太阳系可视化应用，支持离线运行，具有丰富的交互功能、动态拖影效果和中英文双语支持。

![搜索视图](images/earch.png)

## 🌟 功能特性

### 核心功能
- **3D 太阳系渲染**：完整的太阳系，包含太阳和 8 大行星
- **交互式参考系切换**：点击任意行星或使用控制面板切换参考中心
- **动态拖影效果**：显示星体相对于参考中心的运动轨迹
- **地球的月球**：绕地球公转的卫星，带独立的运动轨迹（以地球为参考中心时尤为明显）
- **真实轴倾角**：各行星按真实天文数据倾斜自转（天王星侧躺着旋转，带纤细的垂直光环）
- **程序化纹理**：每个行星都有独特的纹理外观
- **真实光照系统**：太阳点光源无距离衰减（均匀照亮所有行星）+ 环境光/半球光，支持阴影
- **中英文双语支持**：自动检测浏览器语言，支持手动切换

### 控制功能
- **时间速度控制**：0x - 20x 可调节
- **拖影长度控制**：0 - 2 圈（按各自轨道周长）
- **拖影粗细控制**：0.1 - 5.0 可调节
- **显示选项**：可开关拖影、标签显示、性能统计
- **视角预设**：俯视、前视、侧视、斜视、低空 5 种预设角度
- **暂停/继续**：可暂停动画

### 交互方式
- **鼠标拖拽**：旋转视角
- **滚轮**：缩放
- **点击行星**：切换参考中心
- **点击控制面板**：切换参考中心 + 调整相机角度
- **键盘快捷键**：
  - 空格：暂停/继续
  - 1-5：切换预设视角
  - R：重置视角
  - ESC：关闭面板/重置
  - +/-：调整速度
  - H：显示帮助

## 🚀 快速开始

### 前置要求
- 现代浏览器（Chrome、Firefox、Safari、Edge 等）
- 支持 ES Modules 和 WebGL

### 运行方式

#### 方式一：使用 Python HTTP 服务器
```bash
python3 -m http.server 8000
```
然后访问：http://localhost:8000

#### 方式二：使用 Node.js HTTP 服务器
```bash
npx http-server -p 8000
```
然后访问：http://localhost:8000

#### 方式三：使用启动脚本
```bash
./start-server.sh
```

### 离线使用
所有依赖已下载到本地 `libs/` 目录，完全支持离线运行，无需网络连接——包括网络字体（Inter 与 Orbitron 已打包在 `libs/fonts/`）。已验证：页面不发起任何外部网络请求。

## 🎮 使用指南

### 切换参考中心
1. **点击场景中的行星**：立即切换到该行星为参考中心，相机保持不变
2. **点击控制面板按钮**：切换到该行星为参考中心 + 相机移动到俯视角度

### 观察拖影
- 切换参考中心后，所有星体会显示相对于该中心的运动轨迹
- 拖影长度以「圈数」计量（0 - 2 圈）：1.0 表示拖影恰好覆盖该星体相对参考系的一整圈轨道
- 可通过滑块调节拖影长度和粗细

### 查看行星详情
1. 点击任意行星
2. 点击屏幕底部的"📋 显示详情"按钮
3. 查看行星的详细信息（距离、直径、公转周期等）

### 调整视角
- 使用控制面板的"视角预设"按钮
- 或使用键盘快捷键 1-5

### 语言切换
- 点击控制面板顶部的"EN/中文"按钮切换语言
- 页面加载时会自动检测浏览器语言
- 中文环境下自动显示中文，英文环境下显示英文
- 所有 UI 元素和行星标签都会实时切换语言

## 🎨 控制面板

### 时间速度
- 滑块范围：0x - 20x
- 实时调整行星公转速度

### 拖影控制
- **长度**：0 - 2 圈（步进 0.05）。数值表示每个星体保留相对参考系轨迹的圈数；各星体实际点数不同（正比于轨道周长），但保留的圈数一致
- **粗细**：0.1 - 5.0，控制拖影线条的粗细

### 显示选项
- **显示拖影**：开关拖影显示
- **显示标签**：开关行星名称标签（支持双语切换）
- **显示性能统计**：显示实时 FPS / 帧时长 / 渲染调用数 / 三角形数 / 几何体数量

### 画质模式
- **性能**（默认回退）：更低几何细分 + 1024 阴影贴图 + 1024×512 行星贴图
- **高画质**：更高几何细分 + 2048 阴影贴图 + 2048×1024 行星贴图
- **华丽泛光**：完整电影级后期管线（UnrealBloom）+ 增强深空背景，在高画质基础上叠加
- **自动画质**：启动时按设备能力提示（CPU 核数、移动端 UA、屏幕尺寸、DPR）自动选择档位；华丽模式下持续监测平均帧率，若持续低于约 34 FPS 会自动降为高画质（仅降一次）。手动选择档位后不再自动调整
- **自适应相机距离**：最小缩放距离跟随当前天体的真实外扩半径（含大气层壳与光环系统），可贴近观察小天体而不会穿模

### 中心星球
- 9 个按钮，分别对应太阳和 8 大行星
- 点击切换参考中心

### 视角预设
- 俯视：从正上方观察
- 前视：从前方观察
- 侧视：从侧面观察
- 斜视：45 度斜角观察
- 低空：低角度观察

### 语言切换
- 点击"EN/中文"按钮切换中英文
- 启动时自动检测浏览器语言
- 所有 UI 元素和行星标签实时切换语言

## 🔬 特殊功能

### 拖影系统
- 基于相对坐标计算
- 使用固定容量环形缓冲采样，减少内存分配和数组搬移
- 仅在接受新采样点（时间/位移阈值）时重建 TubeGeometry
- 切换参考中心或画质模式时自动重新生成

### 相机系统
- 平滑动画过渡
- 支持多视角预设
- 聚焦时保持星体在中心
- 支持自由旋转和缩放

### 程序化纹理
每个行星都有独特的程序化生成纹理：
- **水星**：陨石坑纹理
- **金星**：噪点纹理
- **地球**：大陆纹理带云层，海洋带高光粗糙度贴图，大气层有昼夜色调
- **火星**：陨石坑纹理 + 稀薄尘埃大气
- **木星**：风暴纹理带大红斑，带清漆光泽
- **土星**：条带纹理带光环，带淡淡的大气
- **天王星**：噪点纹理 + 纤细的垂直光环
- **海王星**：噪点纹理

### 深空星系背景（华丽升级）
- **星云天球**：经度无缝的程序化 FBM 星云（紫/品红/青），内含倾斜银河带。星点只由着色器星场绘制，绝不烘焙进天空贴图，因此任何分辨率下都保持锐利
- **闪烁星场**：约 1.3 万颗着色器驱动恒星（冷白 / 暖黄 / 蓝白），逐星相位错开闪烁，另有密集银河带星流
- **视差纵深**：星云、星场与远景星系随相机以不同速率反向偏移，让天空产生真实纵深感
- **远景旋涡星系**：6 个程序化旋臂星系贴片，在远处缓慢自转
- **流星**：每 5–17 秒偶发一颗划过天空的流星
- **动态太阳等离子层**：基于 3D 噪声的无缝流动 FBM 等离子层（华丽模式更强）
- **不规则星芒**：7 条长度、粗细、亮度各异的星芒，取代对称的四角十字
- **太阳日珥**：偶发从日面边缘升起的不规则等离子丝，随后消散。刻意用数百段带噪声的短线段拼成，而非几何圆弧——规整的圆弧在画面上会被误认为 UI 的 loading 转圈
- **海面反光**：地球海洋通过粗糙度贴图遮罩产生锐利的太阳镜面高光，陆地保持哑光
- **土星环投影**：光环在行星云顶投下阴影，主环外侧另有一圈淡淡的加法混合光晕环

### 太阳系内容
- **主小行星带**：火星与木星之间约 2400 块实例化碎石，位置严格对应真实主带 **2.2–3.2 AU**（视觉距离 155–177），带径向聚集、高度散布（倾角约 4°–7°）、尺寸差异与逐颗色调变化
- **木星特洛伊群**：约 840 块碎石聚集在木星轨道的 **L4（前导 +60°）与 L5（尾随 −60°）** 拉格朗日点，与木星严格同步公转，夹角恒定不漂移
- **固定地表地标**：地球带一块固定大陆，让自转清晰可读；木星大红斑锚定在固定经度

### 天文数据的真实对应
所有行星的轨道与自转数据均与真实值对应：

| 项目 | 处理方式 |
|---|---|
| 轨道半长轴（AU） | 使用真实值（0.39 / 0.72 / 1.00 / 1.52 / 5.20 / 9.50 / 19.20 / 30.10） |
| 视觉距离 | 手工调校的非线性压缩（50→450），保留近密远疏的观感 |
| 公转速度 | 严格与真实轨道周期成反比（`speed = 0.73 / 周期天数`），因此任意时刻行星的相对排列都符合真实太阳系 |
| 自转速度 | 严格与真实自转周期成反比（地球 23.934h 为基准） |
| 自转轴倾角 | 真实值（水星 0.03°、金星 177.4°、地球 23.44°、火星 25.19°、木星 3.13°、土星 26.73°、天王星 97.77°、海王星 28.32°） |
| 自转方向 | 金星与天王星为逆行（`retrogradeSpin`） |
| 月球 | 半径比 0.2726（地球 × 0.2726 ≈ 0.68），公转周期 27.32 天 |

### 运动拖影（华丽升级）
- 拖影长度以「圈数」计量：滑杆设定每个星体保留相对参考系轨迹的完整圈数（0–2，默认 1.0）
- 拖尾**随运动逐渐生成**：加载页面 / 切换参考中心时拖尾从零开始，在约 22 真实秒内拉伸成形（所有天体生长速度一致，外行星无需等待），并以天体实际走过的路程为上限
- **粒子流拖尾**：一串加法混合的光斑精灵沿解析轨迹排布在天体身后——越老的粒子越小、越暗、伴随闪烁，尾端渐渐消散；底层一条半透明轨道光带把粒子流串成整体
- 条带与粒子每帧直接由轨道方程重算（太阳中心为精确圆，行星中心为精确玫瑰线）——无采样缓冲、无历史积累、永远精确
- 拖尾颜色保留每颗行星的本色（土星黄、地球蓝、火星红、海王星青）
- 拖尾颜色保留每颗行星的本色（土星黄、地球蓝、火星红、海王星青）
- 条带与粒子均由解析方程驱动，任意时间速度下轨迹始终精确
- 拖影沿路径渐变：头部（最新采样）粗且亮，尾部细且淡，产生真实的速度感
- 拖影颜色经过降饱和并向深空色调提亮，不再在纯黑背景上刺眼
- 管道分段数随采样点数量增长，复杂路径（如从太阳看去月球的外摆线）保持平滑
- 切换参考中心时立即用当前位置播种每条拖影，避免切换后出现可见的空白空档

### 双语支持
- 基于浏览器语言设置自动检测
- 通过控制面板手动切换语言
- 所有 UI 元素动态切换语言
